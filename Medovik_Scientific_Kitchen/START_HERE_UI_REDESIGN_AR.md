# Medovik Scientific Kitchen — النسخة المعاد تصميمها

1. فك ملف ZIP مع الاحتفاظ بجميع المجلدات.
2. افتح `index.html` بمتصفح Chrome أو Edge محليًا؛ لا يحتاج التطبيق اتصالًا بالإنترنت أو تثبيت مكتبات.
3. اتبع مراحل التصنيع الست: التهيئة → العجين → الخبز → الحشو → التجميع → النتيجة.
4. استخدم «المشاكل» و«الأبحاث» عند الحاجة فقط؛ لا يُعدان من مراحل التصنيع الست.
5. استخدم «عرض متقدم» لإظهار المعارف والتفاصيل؛ «وضع التنفيذ» أثناء الطبخ.
6. في الهاتف، انتقل مباشرة من شبكة المراحل أو عبر الشريط السفلي.
7. قبل «جلسة جديدة» سيطلب التطبيق تأكيدًا حتى لا تفقد البيانات غير المحفوظة.

لم تُغيَّر الوصفات والحشوات والمحركات العلمية، ولذلك تبقى حدود التنبؤ العلمي للإصدار السابق سارية. لتحليل التطوير راجع `docs/UI_REDESIGN_RELEASE_AR.md`، وللتصميم راجع `design-system/medovik-scientific-kitchen/MASTER.md`.
