# Medovik Scientific Kitchen — تقرير إعادة التصميم

**التاريخ:** 24 أكتوبر 2026  
**الحالة:** نسخة تطوير معزولة في `_audit/`، دون تعديل الحزمة الأصلية أو عمل commit أو نشر.

## التغيير الحقيقي

- فصل مسار التصنيع الإلزامي (6 مراحل) عن مرجعي المشاكل والقاعدة العلمية (وجهتان اختياريتان)، دون حذف أي شاشة أو وظيفة.
- بناء نظام بصري موحد: لوحات فاتحة، شريط جانبي داكن، تدرجات هادئة، بطاقات وظيفية، هرمية خطوط عربية واضحة وتباين مدروس.
- استبدال تمرير المراحل أفقيًا على الهاتف بشبكة مراحل مباشرة، مع الإبقاء على جميع وجهات التنقل الثماني.
- إضافة شريط تنقل ثابت للهاتف (السابق / الحالي / التالي)، وتغيير مساره في صفحات المراجع إلى «العودة إلى العمل».
- إضافة ملخص سياقي في بداية كل شاشة يوضح المرحلة واسم الوصفة وقطر القالب وعدد الطبقات ومكان المرحلة في مسار التصنيع.
- الحفاظ على وضع التنفيذ الذي يبرز خطوة الطبخ الحالية وعلى وضع العرض المتقدم بمحتواه العلمي الكامل.
- تأكيد إلزامي قبل بدء جلسة جديدة؛ الإلغاء لا يمس المقادير الحالية.
- أضيف رابط تخطي التنقل، ودلالات وصول `progressbar` صحيحة، وحالات `aria-current`، وإغلاق اللوحة بالأزرار أو مفتاح Escape.
- نظام طباعة أولي يخفي عناصر التحكم والملحقات غير الضرورية.

## ملفات التنفيذ

- `app-v6.js`: تدفق التنقل، مكونات رأس المرحلة، شريط التقدم والعودة، معنى المرجع الاختياري، تأكيد المسح.
- `index.html`: ربط طبقة التصميم الجديدة وتحديث العنوان.
- `ui-redesign.css`: طبقة تصميم وتجاوب معزولة ومقدمة على CSS القديم، لتجنب المخاطرة بملفات الحساب أو الوصفات.
- `design-system/medovik-scientific-kitchen/MASTER.md`: قواعد التصميم ومرجع المصدر.

## خطوط حمراء

لم تُعدل المحركات في `core/` ولا سجلات الوصفات في `data/` ولا الخامات في `ingredients/` ولا مخططات التخزين في `runtime/`. التحسين يقتصر على تجربة الاستخدام وتقديم المعلومات.

## التحقق الفعلي مقابل الحدود

يمكن تشغيل الاختبارات التالية بصورة مستقلة:

```bash
node tests/run-node-tests.js
python tests/browser-smoke.py
python tests/compact-protocol-test.py
python tests/ui-redesign-test.py
python tests/ui-flow-test.py
python tests/ui-safety-test.py
python tests/browser-journey.py
python tests/static-audit.py
node tests/check-source-baseline.js
```

**مهم:** نجاح اختبارات المتصفح داخل صفحة HTML مدمجة لا يساوي اختبار تحميل `file://` على جهاز Windows حقيقي؛ ذلك يحتاج تجربة خارجية. البيانات المحفوظة في رحلة الاختبار استُعيدت عبر لقطة تخزين في سياق متصفح جديد، وليست إثبات إعادة فتح من القرص. ولم تُجر مراجعة استخدام بشرية مستقلة أو اختبار مقارنة تفاعلي مع المنافسين.

## الاستناد إلى المهارة

قُرئت تعليمات `UI/UX Pro Max` من مستودع GitHub الرسمي، ومنها قواعد تركيز الوصول ولمس الأزرار والتباين والتنقل والهواتف. فشلت محاولة `git clone` بسبب حظر DNS داخل البيئة؛ لذلك استُخدمت ملفات المهارة المنشورة مباشرة، ولم يتم تشغيل مولد اقتراحات التصميم CLI أو الادعاء بذلك.

## المهام غير البرمجية الباقية

1. تشغيل الحزمة على Windows والتحقق من الحفظ وإغلاق المتصفح وإعادة فتحه.
2. اختبار مهام قصيرة مع مستخدم حقيقي يقيس الوقت والأخطاء، وليس الانطباعات وحدها.
3. مراجعة تفاعلية متكافئة للمنافسين إذا كان الوصول إلى تطبيقاتهم متاحًا.
4. مراجعة علمية وتوثيقية مستقلة لا تتطلب أجهزة مختبرية.
