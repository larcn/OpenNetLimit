# Medovik Scientific Lab — النسخة التجريبية المعزولة Level 2

هذه نسخة تنفيذ علمي وبرمجي من Medovik v6.0، **وليست تغييرًا في الأصل أو نسخة معتمدة تجريبيًا**.

## التشغيل

1. فك ضغط الحزمة كلها في مجلد واحد؛ لا تفصل `index.html` عن `core/` و`data/` و`runtime/`.
2. افتح `index.html` في Chrome أو Edge أو Firefox.
3. اختر وصفة العجين والحشو والقالب، ثم تابع المراحل الثماني. يتوفر زر **عرض متقدم** للمراجع العلمية، وزر **وضع التنفيذ** لعرض الخطوة العملية الحالية.
4. عند ظهور رسالة نقص معلومات الكثافة، استخدم إدخال وزن الحشو/الكرات مباشرة أو أدخل قيمة معروفة بمصدر واضح؛ لا تعتبر الكثافة التقديرية قياسًا.
5. تعتمد الحسابات على مراجع ومعلومات تركيبية، لكنها لا تضمن قوامًا أو زمن خبز دقيقًا في كل فرن.

## التحقق لمن يرغب
- `bash tests/run-all.sh` لتشغيل الاختبارات البرمجية والعلمية، بعد توفر Node.js وPython وحزمة Playwright وChromium.
- `bash tests/collect-gate-evidence.sh` لحفظ مخرجات كل بوابة داخل `_audit_logs/gates/`؛ التشغيل الجديد يكتب ملفات السجلات داخل مجلد النسخة التي فُك ضغطها.
- `python tests/build-acceptance-matrix.py && python tests/verify-acceptance.py` لإعادة توليد سجل القبول والتحقق من وجود أدلة.

**مهم:** جدول قبول ناجح لا يثبت علميًا دقة النضج أو سلامة التخزين الميكروبيولوجية.
