## 1. البدء السريع (Quick Start)
لا يتطلب التطبيق أي خادم ويب أو اتصال بالإنترنت. يمكنك تشغيله فوراً:
- **النسخة المستقلة الكاملة:** افتح ملف `Medovik_Standalone.html` مباشرة في أي متصفح حديث (Chrome, Firefox, Edge, Safari).
- **النسخة المعيارية المفككة:** افتح ملف `index.html` (أو شغّل خادماً محلياً مثل `npx serve` أو `python -m http.server 8000`).

## 3. التحقق وتشغيل الاختبارات (Verification & Tests)
يتطلب تشغيل الاختبارات وجود بيئة **Node.js 18+** (واختيارياً Python 3 لفحص التدقيق الساكن):

```bash
# 1. تشغيل كامل مجموعة الاختبارات التفصيلية (128 اختباراً)
node --test tests/golden/*.test.js tests/harness/*.test.js tests/persistence/*.test.js tests/scripts/*.test.js tests/unit/*.test.js

# 2. تشغيل مشغّل الاختبارات المجمّع (39 حزمة)
node tests/run-node-tests.js

# 3. التحقق من ثبات اللقطات المرجعية والتطابق الحتمي
node tests/check-source-baseline.js

# 4. فحص بوابة الثوابت الهندسية
node scripts/check-constants.js

# 5. فحص وبناء النسخة المستقلة
node scripts/check-standalone.js

# 6. الفحص الساكن الشامل
python tests/static-audit.py
```

## 4. الميزات الرئيسية المكتملة في الإصدار 1.2
1. **مسارات تحجيم العجين الخمسة المرنة:**
   - القيادة بالسمك المطلوب بعد الخبز (`volume`).
   - القيادة بسمك الفرد الخام بالنشابة (`rawThickness`) مع استنتاج السمك المخبوز ووزن الكرة.
   - القيادة بوزن القطعة الواحدة (`manualBall`).
   - القيادة بوزن العجين الكلي (`totalDoughWeight`) مع زر سريع لوزن الوصفة الأصلية.
   - القيادة بوزن الدقيق المطلوب (`flourBasis`).
   - تكامل دقيق لكثافة العجين التركيبية وتكيف ارتفاع الكيكة الكلي تلقائياً.
2. **نظام بديل الكريمة البودر غير المحلاة (`MedovikCreamPrep`):**
   - نسبة تذويب مرنة (الافتراضي `1 بودر : 2 سائل` بالحليب البارد أو الماء المثلج).
   - تفكيك حتمي دقيق للجرامات وتحليل الأثر على الرطوبة والمواد الصلبة والدهن.
3. **تحسينات واجهة المستخدم وتجربة الاستخدام:**
   - درج أدوات بعرض 540px وتخطيط عمودي أحادي لمنع أي تشويه أو تداخل في النصوص العربية.
   - زر وصول سريع ومباشر في الشريط العلوي لمقارنة وصفتين («مقارنة الوصفات»).
   - قراءة كاملة للأرقام والكسور بالأرقام العربية واللاتينية مع حفظ التركيز.
